# term-markdown

A terminal **markdown** viewer built with `ratatui` + `crossterm`.

## Features

- Headings, *emphasis*, **strong**, ~~strikethrough~~
- Lists:
  1. Ordered items
  2. Second item
- Bullet lists:
  - foo
  - bar
- `inline code` and fenced blocks:

```rust
fn main() {
    println!("hello, term-markdown");
}
```

> A blockquote for good measure.
